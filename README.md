이 프로젝트는 외부 API를 쓰지 않고 내 컴퓨터 안에서 구동되는 로컬 AI 에이전트입니다. 아래 순서대로 세팅해 주세요.

0. 필수 사전 준비

Anaconda (또는 Miniconda): 파이썬 가상환경 관리를 위해 필요합니다. 설치되어 있지 않다면 미리 설치해 주세요.

Git: 코드를 다운로드하기 위해 필요합니다.

1. 프로젝트 다운로드 (Clone)
윈도우 하단 시작 메뉴에서 **Anaconda Prompt**를 검색해서 실행한 뒤, 아래 명령어를 입력하여 코드를 다운로드하고 해당 폴더로 이동합니다.

<터미널 명령어> 

git clone https://github.com/Starlight0307/Team-Build-It

cd Team-Build-It

3. 독립된 파이썬 가상환경 생성 및 접속
패키지 충돌을 막기 위해 현재 프로젝트 전용 가상환경(방)을 만듭니다. (Anaconda Prompt에서 계속 진행합니다.)

<터미널 명령어>

conda create -n ai_agent python=3.11 -y

(💡 Python 3.11 이상이 필요합니다. 더 낮은 버전이면 실행 시 안내 창이 뜹니다.)

conda activate ai_agent


(💡 정상적으로 완료되면 터미널 맨 앞부분의 글자가 (base)에서 (ai_agent)로 바뀝니다!)

3. 필수 패키지 설치 — 자동 (직접 할 필요 없음)
앱을 실행하면(5번) requirements.txt에서 빠진 패키지를 찾아 자동으로 설치합니다.
처음 실행할 때 "루미 준비 중" 창이 뜨고 몇 분 걸릴 수 있으며, 이후 실행부터는
바로 켜집니다. 팀원이 requirements.txt에 패키지를 추가해도 다음 실행 때 그것만
알아서 설치됩니다.

(자동 설치가 실패하면 인터넷 연결을 확인하거나, 아래 명령어로 직접 설치하세요.)

pip install -r requirements.txt


3-1. ⚠️ 필수: 비밀 설정 파일 채우기 (최초 1회)
로그인/회원가입은 Supabase Auth를 통해 이루어지고, 코드에 이미 "공개돼도
안전한" 접속 정보(anon key)가 들어있어서 별도 DB 비밀번호 설정이 필요
없습니다. 다만 이메일 인증코드 발송(SMTP)은 각자 로컬에 설정해야 합니다
(보안상 git에 올리지 않습니다 — 실제 값은 팀 관리자에게 문의하세요):

- `auth/email_config.example.py` → 같은 폴더에 `auth/email_config.py`로 복사 후 SMTP_* 값 채우기

(구글 로그인도 마찬가지로 별도 설정 없이 바로 동작합니다.)

4. ⭐️ 핵심: Ollama 및 AI 모델 설치 (최초 1회)
이 프로그램은 구글 서버가 아닌 내 컴퓨터의 AI 엔진을 사용하므로, 윈도우용 AI 엔진 설치가 필수입니다.

Ollama 공식 홈페이지(ollama.com)에 접속하여 **Windows용 설치 파일(.exe)**을 다운로드하고 설치를 진행해 주세요. 
(설치가 완료되면 윈도우 우측 하단 작업 표시줄에 귀여운 '라마' 아이콘이 생깁니다.)

윈도우 시작 메뉴에서 일반 명령 프롬프트(cmd) 창을 새로 하나 열고, 아래 명령어를 입력하여 똑똑한 Llama 3.1 뇌를 다운로드합니다.

<터미널 명령어>

ollama run llama3.1

(💡 용량이 약 4.7GB이므로 시간이 조금 걸립니다. "Send a message..." 문구가 뜨면 다운로드가 완료된 것입니다. 이제 이 cmd 창은 닫으셔도 좋으나, 작업 표시줄의 라마 아이콘은 켜져 있어야 합니다.)

5. 대망의 프로그램 실행!
다시 아까 켜두었던 Anaconda Prompt 창 (맨 앞에 (ai_agent)라고 적혀있는 창)으로 돌아와서 메인 코드를 실행합니다.

<터미널 명령어>

python app_main.py

(💡 주의: 윈도우에서는 python3 대신 꼭 python 이라고 쳐야 합니다!)

🍎 맥(macOS)에서는 터미널에서 python3 app_main.py 로 실행합니다.
Homebrew로 설치한 파이썬은 시스템 보호 때문에 패키지를 직접 설치할 수 없어서,
루미가 프로젝트 폴더 안에 전용 환경(.venv)을 자동으로 만들고 그 안에 설치합니다.
(맥 기본 내장 파이썬 3.9는 버전이 낮아 쓸 수 없으니 python.org 또는 Homebrew로 3.11 이상을 설치하세요.)

6. 🎙️ 음성 대화 (선택 — 자비스처럼 말로 부르기)
입력창 옆 🎤 버튼(또는 Ctrl+Shift+Space)을 누르고 말하면, 루미가 답변을 소리로 읽어준 뒤 다시 듣습니다.
"그만"이라고 하거나 8초간 말이 없으면 대화가 끝납니다.
👂 버튼을 켜두면 "루미야, ..." / "자비스, ..."로 부를 때마다 대답합니다 (창을 트레이로 숨겨도 동작).
답변을 소리로 듣고 싶지 않으면 ⚙️ 환경설정 > 음성 > "답변 읽어주기"를 끄세요 (음성으로 물어봐도 글로만 답합니다). 설정은 다음 실행 때도 유지됩니다.

- 처음 누를 때 음성 구성요소(requirements-voice.txt, 약 200MB) 설치를 묻고, 첫 사용 시 음성 인식 모델(약 480MB)을 내려받습니다.
- 음성 인식은 인터넷 서버가 아니라 내 컴퓨터 안에서 처리됩니다 (faster-whisper).
- 🪟 Windows: 설정 > 개인 정보 > 마이크에서 "데스크톱 앱의 마이크 액세스"를 켜 주세요. 답변을 소리로 들으려면 한국어 음성이 필요합니다 (한국어 Windows는 기본 포함, 영어판은 설정 > 시간 및 언어 > 음성 > 음성 추가 > 한국어).
- 🍎 macOS: 처음 실행할 때 마이크 권한 창이 뜨면 허용해 주세요 (터미널/VS Code에서 실행했다면 그 앱에 권한이 부여됩니다).
- Intel Mac, Windows ARM은 음성 구성요소가 지원되지 않을 수 있습니다.

7. 🖥️ 화면 보고 스스로 작업하기 (선택)
루미가 화면을 보고 마우스/키보드로 직접 작업합니다. 화면은 인터넷으로 보내지 않고 로컬 비전 모델(Ollama)로 처리합니다.

- "직접 메모장 열고 '안녕'이라고 써줘", "화면에서 설정 버튼 눌러줘"처럼 **직접 / 대신 / 화면에서**로 요청하거나, 입력창 옆 🖥️ 버튼(화면 조작 모드)을 켜고 요청하세요.
- "지금 화면에 뭐가 보여?", "화면 내용 요약해줘"는 조작 없이 화면만 보고 답합니다.
- 작업 중에는 루미 창이 숨고 오른쪽 아래에 진행 상황이 표시됩니다. **Esc** 또는 **마우스를 화면 왼쪽 위 모서리로 밀면** 즉시 멈춥니다 (트레이 메뉴 "화면 작업 중지"도 가능).
- 삭제/전송/결제/제출/종료처럼 되돌리기 어려운 동작은 실행 전에 확인 창이 뜹니다. 비밀번호·카드 정보는 입력하지 않습니다.
- 처음 쓸 때 화면 인식 모델(qwen3-vl:8b-instruct, 약 6GB)을 내려받을지 묻습니다. 직접 받으려면: `ollama pull qwen3-vl:8b-instruct`
  (RAM 8GB PC는 settings/config.py의 SCREEN_MODEL을 "qwen3-vl:4b-instruct"로 바꾸면 가볍습니다.)
- 🍎 macOS: 시스템 설정 > 개인정보 보호 및 보안에서 **화면 기록**과 **손쉬운 사용**을 루미를 실행한 프로그램(터미널/VS Code/Python)에 허용한 뒤 루미를 다시 실행하세요. 권한이 없으면 루미가 안내하고 설정 화면을 열어줍니다.
- 🪟 Windows: 별도 권한은 필요 없지만, 관리자 권한으로 실행된 프로그램 창은 조작할 수 없습니다.

8. 🏠 홈 화면
왼쪽에 시스템 상태 · 날씨 · 오늘 일정 · 할 일 · 세션 패널, 가운데 루미 오브(음성 상태에 따라 움직임, 누르면 음성 대화), 오른쪽에 대화 패널이 있습니다.
- 날씨는 Open-Meteo(무료, 인증 키 없음)에서 30분마다 가져옵니다. 처음 실행하면 현재 위치를 자동으로 찾습니다
  (Windows는 Windows 위치 서비스 → 안 되면 인터넷 주소 기준, macOS는 인터넷 주소 기준). 인터넷 주소 기준 위치는
  구·시 단위로 틀릴 수 있어서 ⚙️ 환경설정 > 날씨에서 "📍 내 위치 찾기"로 다시 찾거나 지역을 직접 고칠 수 있습니다.
  위치를 찾을 때 이 PC의 공인 IP가 위치 서비스(ipwho.is 등)로, 날씨를 가져올 때 지역/좌표가 Open-Meteo로 전송됩니다.
- ⚙️ 환경설정 > 홈 화면 위젯에서 왼쪽 위젯을 켜고 끄거나 ▲▼로 순서를 바꿀 수 있습니다 (바로 적용, 다음 실행에도 유지).
- 창이 좁으면 왼쪽 패널 → 가운데 오브 순서로 숨어서 대화 공간을 확보합니다.

9. 🪄 OpenClaw 스킬 (선택)
OpenClaw/ClawHub 스킬(SKILL.md)을 루미에서 그대로 쓸 수 있습니다. 스킬은 "설명서"라서, 루미의 AI가
지침을 읽고 명령 실행·파일 읽기·웹 가져오기로 작업합니다 (core/skills.py, core/skill_agent.py).

- 상단 🪄 스킬 화면에서 ClawHub 스킬을 검색해 설치하거나 zip 파일로 설치합니다. 설치 전에 SKILL.md 전체를 보여줍니다.
- OpenClaw를 이미 쓰고 있다면 `~/.openclaw/skills`, `~/.agents/skills`의 스킬도 자동으로 보입니다.
  루미에서 설치한 스킬은 프로젝트의 `skills/` 폴더에 저장됩니다 (git에는 올라가지 않음).
- 대화에서 `$스킬이름`으로 부르거나(예: `$weather 서울 날씨 알려줘`), "자동 사용"을 켜두면 알맞은 스킬을 루미가 고릅니다.
  일정·할 일·PC 상태처럼 루미 기본 기능으로 할 일은 스킬로 가로채지 않습니다.
- ⚠️ 스킬이 명령을 실행하려 할 때마다 확인 창이 뜹니다 ("이 스킬은 계속 허용"을 고르면 앱을 끌 때까지 묻지 않음).
  외부 스킬은 믿을 수 없는 코드로 생각하고, 내용을 확인한 뒤 설치하세요.
- 스킬에 필요한 프로그램(`requires.bins`)이나 환경변수(`requires.env`, `.env`에 넣으면 됨)가 없으면 목록에 이유가 표시되고 쓰이지 않습니다.
  OpenClaw 전용 설정(`requires.config`)이 필요한 스킬은 루미에서 쓸 수 없습니다.
- Windows에서는 Git Bash가 있으면 bash로, 없으면 PowerShell로 명령을 실행합니다 (bash 문법 스킬은 Git Bash 설치를 권장).
