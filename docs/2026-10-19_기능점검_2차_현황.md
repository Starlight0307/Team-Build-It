## 3. 요청 크기(토큰) 줄이기 — 기능은 그대로, 약 48% 감소

같은 질문 32개를 고치기 전/후 실제 AI로 2번씩 돌려 **AI가 고른 기능**을 비교했어요.

| | 고치기 전 | 고친 후 |
|---|---|---|
| "안녕" (매번 붙는 고정분) | 2,282토큰 | **518토큰** |
| 32개 질문 합계 | 97,932토큰 | **51,361토큰** |
| 예산(3,500) 초과 질문 | 6개 (1개는 문맥 초과로 잘림) | **0개** |
| AI가 고른 기능 | — | 32개 중 30개 같음, 달라진 2개도 같은 목적의 기능 |

줄인 것:
- 시스템 안내문에 **설치된 함수 169개 이름을 매번 다 적던 것**(약 1,300토큰) → 이번 요청에 실제로 보내는 함수만
- 가격·IoT·악성코드 같은 **선택 규칙은 해당 기능이 실릴 때만** (규칙 문장 자체는 그대로)
- "루미 기능 설명해줘": 기능 169개 설명(8,444토큰, 잘림) → 기능 요약 목록(약 500토큰), 17가지 기능을 빠짐없이 소개

확인하며 본 것: 일정 제목이 이상하게 들어가거나("주울 안호") 검색어에 "지난주에 받은"이 들어가도, 루미가 사용자 문장으로 다시 고쳐서 실제 저장·검색엔 영향 없음.

측정 결과 질문별(실제 토큰): 날씨 1,318 · 일정 등록 1,674 · 할 일 1,913 · 가계부 1,503 · 타이머 1,249 · 대용량 파일 2,373 · 메일 초안 2,844 · 전등 2,348 · 연결된 기기 2,347 · 의심 프로세스 종료 3,281 (가장 큼)

## 4. 보안 답변을 사용자용으로

"개발자용 답변 같다"는 피드백을 반영해, **무엇을 확인했고 → 결과가 어떤지 → 뭘 하면 되는지** 순서로 바꿨어요.

| 답변 | 바뀐 점 |
|---|---|
| 시스템 보안 점검 | 항목마다 쉬운 설명. 예) "🚨 Windows 업데이트: 마지막 업데이트가 238일 전이에요. … '업데이트 확인'을 눌러 주세요." 확인 못 한 항목은 이유를 바로 알려줌(관리자 권한 필요, Windows Home 등). 위험 항목이 있으면 점수보다 그 항목을 먼저 챙기라고 안내 |
| 네트워크·악성코드 점검 | 항목마다 "무엇을 봤는지 + 결과(+ 문제면 이유)". 예) "✅ 예약 작업: 정해진 시간에 몰래 실행되도록 등록된 작업이 있는지 봤는데, 이상 없어요." |
| 내 PC 안전해? (전체 점검) | 세 리포트 원본을 이어 붙이던 것 → 영역별(🌐/🦠/🖥️)로 묶은 한 답변 + "먼저 챙길 항목" |
| 앱 시작 시 보안 점검 말풍선 | "열린 TCP 포트 12개 — 목록에 없는 포트 3개, 방화벽 설정상 막힌 위험 포트 3개" → "바깥에서 접속할 수 있게 열린 통로(TCP 포트) 12개를 확인했는데, 위험한 것은 없어요. 위험할 수 있는 3개는 방화벽이 이미 막고 있어요. …" |
