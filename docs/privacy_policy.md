# 루미(Lumi) 개인정보 처리방침

시행일: 2026년 11월 6일 · 대상 버전: v1.3.1 이후

**[작성 필요]** 표시는 공개 전에 팀에서 채워야 하는 항목입니다.

## 1. 핵심 요약

- 대화, 음성, 화면, 회의록은 **이 컴퓨터 안에서만** 처리하며 루미 서버로 보내지 않습니다.
- 서버에는 **로그인에 필요한 계정 정보와 로그인 기록**만 저장합니다.
- 연결한 서비스(구글, 카카오, 증권사 등)와 주고받는 내용은 해당 기능을 쓸 때만 전송합니다.
- 광고나 사용 행태 분석 도구를 쓰지 않습니다.

## 2. 서버에 저장하는 정보

| 항목 | 목적 | 시점 |
|---|---|---|
| 아이디, 비밀번호, 이메일, 이름, 전화번호, 생년월일, 회원번호 | 회원 가입과 본인 확인 | 회원 가입 |
| 구글·카카오 로그인 연결 정보 | 소셜 로그인과 계정 연동 | 소셜 로그인·연동 |
| 로그인 시각, 로그인 방식, 기기 종류(예: Windows 11) | 계정 보호, 로그인 기록 표시 | 로그인 |

컴퓨터 이름은 저장하지 않으며, 로그인 기록에 IP 주소를 따로 적지 않습니다. 비밀번호는 인증 서비스가 처리하며 팀이 원문을 볼 수 없습니다.

## 3. 이 컴퓨터에만 저장하는 정보

대화 기록, 루미가 기억한 내용, 설정, 메모, 할 일, 일정, 지출, 앱 사용 기록, 주식 즐겨찾기와 차트 표시, 회의록.

민감한 항목(연결 토큰, 앱 키, 앱 전용 암호, 회의록 등)은 암호화해 저장합니다. 이 정보는 사용자의 컴퓨터에 있어 팀이 볼 수 없습니다.

## 4. 음성, 화면, 회의 녹음

- **호출어:** 기본으로 켜져 있어, 음성 구성요소를 설치하면 앱이 켜진 동안 마이크가 "루미야"를 기다립니다. 환경설정 > 음성 또는 트레이 메뉴에서 끌 수 있습니다.
- **음성 인식과 AI 답변:** 이 컴퓨터 안의 모델(faster-whisper, Ollama)이 처리합니다.
- **화면 작업:** 사용자가 요청했을 때만 화면을 캡처하고 창의 글자를 읽어 이 컴퓨터 안의 모델에 넘깁니다. 화면에 보이는 개인정보도 함께 처리될 수 있습니다.
- **회의 녹음:** 사용자가 시작했을 때만 녹음합니다. 받아쓴 뒤 녹음 파일을 지우고, 글과 요약을 암호화해 저장합니다. 받아쓰기에 실패하면 복구를 위해 녹음 파일을 남깁니다. **녹음 전에 참석자에게 알려 주세요.**

## 5. 외부 서비스 (처리 위탁과 제공)

해당 기능을 쓸 때만 전송합니다.

| 받는 곳 | 보내는 내용 | 기능 |
|---|---|---|
| Supabase | 2번의 계정 정보, 로그인 기록 | 회원 계정 |
| Google | 이메일 인증 메일 수신 주소 | 이메일 인증 메일 발송 |
| Google | 일정 내용, 로그인 토큰 | 구글 로그인, 구글 캘린더 |
| Kakao | 일정 내용, 로그인 토큰 | 카카오 로그인, 톡캘린더 |
| Apple | Apple ID, 앱 전용 암호, 일정 내용 | iCloud 캘린더 연결 시 |
| 연결한 증권사 | 앱 키, 계좌번호, 종목, 주문 내용 | 주식 조회와 주문 |
| 공공데이터포털 | 조회한 종목 정보 | 계좌 없이 주식 시세 조회 |
| Open-Meteo | 도시 또는 대략의 좌표 | 날씨 |
| ipinfo.io, ipwho.is, ip-api.com | 통신상 전달되는 IP 주소 | 현재 도시 추정 |
| GitHub | 통신상 전달되는 IP 주소 | 업데이트 확인, 내려받기 |
| Hugging Face, Ollama | 통신상 전달되는 IP 주소 | 음성·AI 모델 내려받기 |
| 검색 사이트, 쇼핑 사이트 | 검색어 | 웹 검색, 최저가 검색 |

연결된 서비스의 처리방침은 각 회사의 방침을 따릅니다. 일부 서비스는 국외에서 처리될 수 있습니다. **[작성 필요: 국외 이전 항목, 업체별 국가와 보유 기간 확인]**

## 6. 보유 기간과 파기

- **이 컴퓨터의 정보:** 사용자가 지우거나 탈퇴할 때까지 보관합니다. 탈퇴하면 이 컴퓨터의 대화 기록, 설정, 기억 등을 삭제합니다.
- **연결 해제:** 톡캘린더 연결을 끊으면 이 컴퓨터의 토큰을 지웁니다. 카카오에서 앱 연결을 해제하면 서버의 카카오 로그인 연결을 지웁니다. 카카오로만 가입한 계정은 로그인 상태를 끊되, 계정 정보는 **아래 삭제 요청 전까지 남습니다.**
- **서버 계정 정보:** 현재 탈퇴하면 그 계정으로 다시 로그인할 수 없게 되지만, 서버의 계정 정보와 로그인 기록은 **자동으로 삭제되지 않습니다.** 삭제를 원하면 8번 연락처로 요청해 주세요. 확인 후 관리자가 삭제합니다.
